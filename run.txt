HOW TO RUN (local, Windows PowerShell)
=================================================

All commands are run from the project root.

FIRST TIME
  1. Copy .env.example to .env.worker1 ... .env.worker4
     (change WORKER_ID, PORT, ADVERTISE_ADDR, DATA_DIR in each)
  2. cargo build

START A WORKER (one terminal per worker, leave it open)
  cargo run -p worker -- .env.worker1
  cargo run -p worker -- .env.worker2
  cargo run -p worker -- .env.worker3
  cargo run -p worker -- .env.worker4

  You should see "listening on 0.0.0.0:808X".
  "registration attempt N failed" is normal until the controller is running.

STOP A WORKER
  Ctrl+C in its terminal. Its chunks stay in ./data/workerX.

CHECK A WORKER IS UP
  curl.exe -s http://localhost:8081/health

WIPE ALL STORED DATA
  Remove-Item -Recurse -Force .\data

NOTES
  - Use curl.exe, not curl, in PowerShell.
  - Port 8080 is used by another program on this PC, so the
    controller runs on 9000.
  - Variables already set in the terminal override the .env file.
    If something looks wrong, open a fresh terminal.
